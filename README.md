## Featured Projects

### Café POS (Bunney POS)

A desktop point-of-sale and accounting app for a small café, built with Python, PyQt6, and SQLite. It runs offline on Windows and Linux, so nothing depends on a server or an internet connection. The interface is Arabic and right-to-left because that's who it was built for: a touch-first product grid, shift management with drawer counts, role permissions for cashier and admin, ESC/POS thermal receipt printing, and local USB backups on every shift close.

### Video Translator

An Android app that transcribes and translates videos, then burns the subtitles straight into the file. Built with Flutter for the app and a FastAPI backend. Transcription runs on the device with Whisper, so audio never leaves the phone. Translation covers more than 50 languages, and subtitle rendering is done at CRF 18 with a clear outlined font. It also handles novels (TXT/EPUB) and manga.

### Auth & Onboarding UI

A Flutter implementation of login, sign up, and onboarding flows. Form validation with live error feedback, password visibility toggle, social login buttons, and page indicators for the onboarding steps. Material Design 3 throughout, responsive on any screen size.
