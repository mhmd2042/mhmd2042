## مشاريع مميزة

### 🎯 نظام نقاط بيع للمقاهي
تطبيق سطح مكتب مبني بـ Python و PyQt6، مصمم خصيصاً للمقاهي العربية. واجهة عربية RTL كاملة، يعمل بدون اتصال بالإنترنت، ويدير الطلبات والمخزون والمبيعات بكفاءة.

### 🎬 مترجم الفيديو
تطبيق Flutter مع واجهة خلفية FastAPI. يستخدم Whisper لتحويل الكلام إلى نص على الجهاز، ثم يحرق الترجمة على الفيديو باستخدام VAAPI أو CPU.

### 🔐 واجهات المصادقة والتعريف
تطبيق Flutter يعرض تدفقات تسجيل الدخول والتسجيل والتعريف بالمستخدم بتصميم نظيف ومتجاوب.
